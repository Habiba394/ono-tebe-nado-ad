# Оно тебе надо

Учебный проект — вёрстка главной страницы сайта аукциона «Оно тебе надо» по макету из Figma («1 спринт. Проектная работа»).

## Ссылка на проект

https://github.com/Habiba394/ono-tebe-nado-ad

## Что реализовано

- семантическая вёрстка (`header`, `nav`, `main`, `section`, `article`, `footer`, `address`);
- именование классов по методологии БЭМ;
- шрифт Raleway, подключённый через `@font-face` (папка `fonts`);
- вёрстка страницы шириной 1100 px по центру окна браузера, как в макете;
- Grid и Flexbox, без `!important` и встроенных стилей;
- у всех контентных изображений есть `alt`.

## Структура

```
.github/workflows/   автоматическая проверка
fonts/               шрифты Raleway и fonts.css
images/              изображения и иконки
styles/              global.css и style.css
index.html
```

## Запуск

Откройте `index.html` в браузере. Сборка не требуется.
