# Оно тебе надо

Учебный проект — адаптивная вёрстка сайта аукциона «Оно тебе надо» по макету из Figma («1 спринт. Проектная работа»).

## Ссылка на опубликованный проект

https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/

## Что реализовано

- семантическая вёрстка (`header`, `nav`, `main`, `section`, `article`, `footer`, `address`);
- именование классов по методологии БЭМ;
- шрифт Raleway, подключённый через `@font-face` (папка `fonts`);
- адаптивность: 1440 / 1024 / 768 / 480 / 320 px;
- Grid и Flexbox, без использования `!important` и встроенных стилей;
- у всех контентных изображений есть `alt`.

## Структура

```
.github/workflows/   автоматическая публикация
fonts/               шрифты Raleway и fonts.css
images/              изображения и иконки
styles/              global.css и style.css
index.html
```

## Запуск

Откройте `index.html` в браузере. Сборка не требуется.
